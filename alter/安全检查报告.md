# 危险链接安全检查报告

- 检查日期：2026-11-14
- 检查范围：仓库全部文件，以及从 `output/dmff.txt` 出发能访问到的全部内容。具体包括：
  - 5 个仓、26 条线路（已解密）
  - 配置引用的 695 个规则文件、406 个 JS/Python 脚本、47 个直播列表
  - 64 个 spider jar
- 合计 3316 个链接、3042 个主机。其中 1364 个是直播流服务器，只做了黑名单比对。

## 一、检查方法

1. **黑名单本地比对**：下载公开威胁库后在本机比对，没有把链接发给任何外部服务。比对时同时检查主机本身和它的上级域名。
   - 用到的威胁库：hagezi 威胁情报 TIF（142 万条）、hagezi 博彩/色情/假冒、URLhaus 恶意软件、OpenPhish 和 phishing-filter 钓鱼库、StevenBlack。
2. **主页探测**：请求了 1199 个网站主页（直播流服务器和 GitHub、豆瓣等大平台除外），检查以下几项：
   - 是否停放待售
   - 是否跳转到别的域名，包括 JS 和 meta 跳转
   - 页面里有没有博彩、色情、挖矿内容
   - 跳转目标也一并做了黑名单比对
3. **jar 静态扫描**：解开 59 个能下载的 jar 中的 dex，查找以下可疑特征，并提取内置的网址：
   - 执行命令、root、读取设备标识、通讯录/短信、安装 APK、录屏、定位、挖矿、动态加载

## 二、结论

**你仓库里自己的文件没有危险链接。** 两个一木配置、各个列表文件都没有命中。.md 文档里唯一的命中是示例地址 `0.0.0.0`，属于误报。

**问题全部来自引用的第三方线路。** 这些线路很多是两三年前的配置，里面的影视站、解析接口大量失效。失效后的域名被人抢注，拿去做博彩、色情和流量变现。没有发现挖矿脚本，也没有发现明确的恶意软件下载。

## 四、具体发现

### 1. 过期域名被抢注（31 个跳到同一个导流网络）
31 个已经失效的影视站、解析域名，现在都跳到 `gotowww.aipages.dev`，再用 JS 转到 `global.urldance.com` 或搜索页，属于过期域名流量变现。眼下没有看到恶意代码，但页面内容完全由抢注方控制，随时可能换成别的。另有 19 个域名是停放待售页。

### 3. 威胁情报库命中（12 个）
`www.miaoys.cc`、`yinshi.eatuo.com`、`gy.lubao2.de5.net`、`yydsys.de5.net`、`alist.youte.ml`、`cfss.cc`、`meow.tg`、`9763.kstore.vip`（写在南风的一个 jar 里，现返回 404）、`epg.cdn.loc.cc`（香雅情的 EPG 地址 `cdn.1678520.xyz` 跳转过去的目标），以及「垃圾堆成山」直播源里的 `qwas.eatuo.com`、`xjayrf.eatuo.com`、`gxfrg007.8800.org`。

威胁情报库只说明这些域名被某个情报源标记过，不代表现在一定在作恶。本次探测没有在它们上面看到恶意下载或钓鱼页。

### 4. 色情内容
- 直播：小林线路的「垃圾堆成山」（`qu.ax/ktVO.txt`）含大量色情频道，来自 adultiptv.net、redtraffic.xyz、mycamtv.com。`qu.ax` 是匿名文件站，内容随时可能被换掉。
- 色情名单里另有一些命中，例如 360kan、libvio、anime1、assrt 等，属于综合影视站或字幕站。这类站点被色情名单收录，多半是因为站内有少量相关内容，属于宽泛分类，不算危险。
- FongMi 的 `custom_spider.jar` 里内置了 jable、missav、hanime 等成人站的爬虫代码。但这次检查的配置里没有站点调用它们，所以不会出现在界面上。

### 5. jar（TVBox 会直接执行的代码）
- 共 64 个，59 个能下载并完成扫描。只有 19 个在配置里写了 md5 校验，其余被替换了也不会被发现；只有 1 个用明文 HTTP 下载。
- 「执行系统命令」「chmod 777」「本地代理」这类特征在 TVBox jar 里很常见，通常是给自带的代理或 alist 程序加执行权限，不能单凭这一点判定恶意。「安装APK」命中的其实是一张文件类型对照表，并不是安装动作。
- 值得注意的有三个：
  - `小🍎.jar`（小林）：读取设备号。
  - `Yoursmile.jar`（南风）：引用了录屏类 MediaProjection，带原生库。在 Android 上录屏必须经用户在弹窗里同意。
  - `pg.jar`（高天流云 js）：引用了联系人类名，但没有读取短信、通话记录的路径。
- 另有 6 个 jar 带原生库（.so），静态扫描看不到原生代码里做了什么。

### 6. 配置层面
- DNS（doh）设置用的都是 Google、Cloudflare、AdGuard、阿里、腾讯、360 这类公共 DNS。
- 规则（rules）多数是在播放时过滤视频里插播的广告片段，属于正常功能。
- 王二小、放牛娃把咪咕、移动的官方直播域名强制改到第三方服务器 `188766.xyz`。这只影响 TVBox 内的播放，但你看了哪些频道，那台服务器都能看到。
- 饭太硬、挺好分享、肥猫也有少量域名改写，都是给特定直播或图片域名换线路，风险低。

### 7. 仓库文档
- 夸克网盘、123 网盘的 APK 下载链接（8 个）：不是官方渠道，无法确认 APK 有没有被改过。建议尽量从官方 GitHub Releases 下载。
- 宝塔面板安装命令（`io.bt.sb`）：用 root 权限执行网上下载的脚本。这是宝塔官方提供的安装方式，但执行前最好先确认来源。

## 五、建议

1. **删除** 小林、香雅情镜像两条线路，它们出现在补充系列、多线路接口zq.txt、一木多线路.json、多线路接口.txt 中。其中补充系列里的这两条是上一轮由我加入的。
2. **建议删除** 宝盒线路和月光宝盒（含跳转博彩注册页的站点）。如果要保留，不要在里面点开名字陌生的站点。
3. 高天流云 js、老刘备、南风可以保留，但里面失效、被抢注的站点不少，建议优先用其他线路。
4. 电视、盒子尽量更新系统 WebView（Android System WebView）。
5. 这类第三方线路变化很快，建议定期复查。本次的脚本和数据都保存在本机，可以重跑。

## 六、局限

- 只能看到第三方配置在当前时刻的内容。线路作者随时可以改配置、换 jar。
- jar 用了混淆或加密的话，静态扫描看不到隐藏的行为；原生 .so 库也没有分析。
- 黑名单有误报，也有漏报。主页探测只看首页，没有模拟实际播放。
